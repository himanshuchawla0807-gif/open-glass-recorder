# Changelog

## [0.0.1.2] - 2026-10-19

### Changed

- Default demo restores the approved reference rendering, including circular surround, inner lens and reactive recording animation.
- Preserved the independent MIT demo at independent.html, alongside its lab and composer example.
- Added the approved inline chat example with navy gradient and transparent glass.
- Documented third-party provenance and excluded recovered renderer files from our MIT grant.
- Restored recorder click targets keep a constant diameter while recording.


## [0.0.1.1] - 2026-10-19

### Added

- A live component lab with three working variants and editable dimensions, tint and gradients.
- An inline composer example and copyable configurations.
- Original navy space gradients that work without wallpaper images.
- Runtime geometry and appearance configuration, browser regression harness and broader syntax checks.

### Fixed

- Button diameter now stays constant while the recording pill expands.
- Recording URLs survive cached back navigation in the lab and composer example.


## [0.0.1.0] - 2026-10-18

### Added

- Record, play back and download voice notes locally.
- Independent WebGL2 glass rendering with spring motion and audio-driven color.
- Three owner-supplied landscape wallpapers and responsive layouts.
- Reusable component, reduced-motion support, CSS fallback and transparent mode.
- Tests, browser verification, documented provenance and GitHub Pages workflow.
